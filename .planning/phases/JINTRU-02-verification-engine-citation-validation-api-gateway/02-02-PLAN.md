<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser client -> FastAPI gateway | Untrusted HTTP requests and CORS preflights cross into the app |
| FastAPI gateway -> SQLite | User-supplied identifiers reach parameterized database queries |
| Provider failure -> HTTP response | Internal exception details risk leaking configuration or key material |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Tampering | `/api/v1/verifications` request bodies | high | mitigate | Pydantic `min_length=5`/`max_length=500` bounds plus a `RequestValidationError` handler returning a structured 422 envelope |
| T-02-07 | Information Disclosure | `GET /api/v1/health`, error envelopes | high | mitigate | Health reports only `configured`/`missing` booleans; envelopes never include `BRAVE_API_KEY`/`META_API_KEY` values or stack traces |
| T-02-08 | Injection | `DELETE`/`GET /verifications/{id}` identifiers | medium | mitigate | Identifiers travel as `?`-bound parameters through `aiosqlite`, never string-formatted into SQL |
| T-02-09 | Cross-Site Request Forgery | CORS middleware configuration | medium | mitigate | Explicit origin allowlist (`localhost:3000`, `localhost:5173`) with `allow_credentials=False` |
| T-02-10 | Denial of Service | Pipeline invocation from `POST /verifications` | high | mitigate | The gateway surfaces `ProviderTimeoutError` as a bounded 504 rather than hanging; no retry loop is added at the route layer |
| T-02-SC | Tampering | Dependencies (`pyproject.toml`) | high | mitigate | Gateway uses only already-declared FastAPI/httpx/aiosqlite dependencies; `pip-audit` and `semgrep` remain in the dev toolchain |
</threat_model>
