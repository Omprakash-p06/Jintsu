<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted claim text -> Gate A classifier | Arbitrary user input crosses into deterministic regex classification |
| Retrieved search snippets -> synthesis prompt | Third-party web text crosses into the LLM context window |
| Model output -> application verdict | Untrusted structured LLM output crosses into the authoritative verdict decision |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `sanitize_and_quarantine` (prompt injection) | high | mitigate | Strip control/zero-width characters, quarantine `system prompt:` / `override verdict` / `ignore instructions` snippets, and exclude quarantined sources from the synthesis payload while recording the action in limitations |
| T-02-02 | Spoofing | `group_sources` (`source_family_id`) | high | mitigate | Cluster by canonical registered domain and word-boundary wire tokens so syndicated copies cannot fabricate two-domain corroboration |
| T-02-03 | Elevation of Privilege | `apply_verdict_policy` | high | mitigate | Deterministic application-level guardrails veto any `supported` verdict contradicted by active refuting evidence or backed by a single family |
| T-02-04 | Denial of Service | `VerificationPipeline.verify` (budget) | high | mitigate | Monotonic deadline with `min(stage_budget, remaining)` subordinate timeouts, single query per stage, and clean `ProviderTimeoutError` abort below the 2.5s synthesis window |
| T-02-05 | Repudiation | `validate_citations` (fabricated excerpts) | medium | mitigate | Tier 1 ID intersection plus Tier 2 normalized verbatim substring matching drops ungrounded citations instead of trusting the model |
| T-02-SC | Tampering | Dependencies (`pyproject.toml`) | high | mitigate | No new runtime dependencies are introduced by this plan; `pip-audit` and `semgrep` remain in the dev toolchain |
</threat_model>
