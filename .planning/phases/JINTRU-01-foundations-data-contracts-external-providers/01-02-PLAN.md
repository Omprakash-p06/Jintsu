  <name>Task 2: Brave Search API Provider Adapter (Snippets and LLM Context)</name>
  <files>backend/app/providers/brave.py, backend/tests/unit/test_providers.py</files>
  <behavior>
    - Test 1: In `mode="snippets"`, queries `/res/v1/web/search` and extracts `web.results[]` mapping `url`, `title`, and `description` to `snippet`.
    - Test 2: In `mode="context"`, queries `/res/v1/llm/context` and parses passages under `grounding.generic[].snippets` into `SourceItem.snippet`.
    - Test 3: Normalization produces deterministic `source_id = f"src_{idx+1}"`, SHA-256 `content_hash`, and maps wire attribution tokens (`Associated Press`, `Reuters`, `PR Newswire`) to `source_family_id`.
    - Test 4: Handles request timeouts raising `ProviderTimeoutError` and HTTP errors raising `ProviderUnavailableError`.
  </behavior>
  <action>
    Implement `BraveSearchProvider` in `backend/app/providers/brave.py` strictly per D-12, `misc/docs/designs/jintru_claim_verification.md` § Phase 3, and repository rules in `AGENTS.md`:
    1. Define `class BraveSearchProvider(SearchProvider)`.
    2. In `search(query, count=5, mode="snippets", timeout=3.0)`:
       - Header: `{"X-Subscription-Token": settings.BRAVE_API_KEY, "Accept": "application/json"}`.
       - If `mode == "snippets"`: send GET to `https://api.search.brave.com/res/v1/web/search` with params `{"q": query, "count": count}`. Parse `web.results[]`.
       - If `mode == "context"`: send GET to `https://api.search.brave.com/res/v1/llm/context` with params `{"q": query}`. Extract passages under `grounding.generic[].snippets`, mapping extracted snippet text to `snippet`, item URL to `url`, title to `title`, and `source_type="llm_context"`.
       - Normalize each entry into a dict conforming to `SourceItem`:
         - Assign `source_id = f"src_{idx+1}"`.
         - Extract domain from URL via `urllib.parse.urlparse(url).netloc.lower()`.
         - Wire attribution token extraction: if `title` or `snippet` references "Associated Press", "AP", "Reuters", or "PR Newswire", map `source_family_id` to the normalized wire token; otherwise use canonical registered domain.
         - Compute `content_hash = hashlib.sha256(snippet.encode('utf-8')).hexdigest()`.
         - Set `retrieved_at = datetime.now(timezone.utc).isoformat()`.
       - Handle `httpx.TimeoutException` by raising `ProviderTimeoutError("Brave search request timed out", code="BRAVE_TIMEOUT")`.
       - Handle `httpx.HTTPStatusError` and `httpx.RequestError` by raising `ProviderUnavailableError("Brave search service unavailable", code="BRAVE_UNAVAILABLE")`.
    3. Add unit tests in `backend/tests/unit/test_providers.py` using `unittest.mock` / `respx` / `httpx.MockTransport` verifying payload transformation for both modes, wire service extraction, and error handling.
  </action>
  <verify>
    <automated>pytest backend/tests/unit/test_providers.py -k "test_brave" -v</automated>
  </verify>
  <done>
    `BraveSearchProvider` accurately parses `/res/v1/web/search` and `/res/v1/llm/context`, normalizes wire/domain family IDs, computes SHA-256 hashes, and translates network exceptions to domain errors.
  </done>
