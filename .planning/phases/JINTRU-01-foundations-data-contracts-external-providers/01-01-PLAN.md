## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> API Schemas | Untrusted HTTP request payloads cross into Pydantic schema validation |
| Application -> Database | Application records serialized to flat SQLite database file on disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `backend/app/api/schemas.py` | medium | mitigate | Enforce strict Pydantic min/max string boundaries (5-500 chars) and strict Literal enum constraints on verdicts and stances |
| T-01-02 | Denial of Service | `backend/app/db/database.py` | high | mitigate | Enforce WAL mode, `busy_timeout=5000`, `synchronous=NORMAL`, and 3-attempt exponential backoff on write contention |

</threat_model>
